AI가 습관적으로 쓰는 장식 이모지를 쓰지 않는다.

**Why:** 2026-08-09 부모로 2기 진행 중 사용자가 "AI가 자주 쓰는 이모지 같은 것은 제외했으면 좋겠어"라고 요청. 그전까지 보고에 완료 체크마크·축하 이모지, 문서 파비콘 등을 쓰고 있었다.

**How to apply:**
- 대상: 채팅 보고, 커밋 메시지, HTML 문서 본문, 제품 UI 카피, 아티팩트 등 전부
- 금지 예: 완료 체크·경고 삼각형·로켓·반짝이·전구·불꽃·축하 폭죽·달 등 장식 목적 이모지
- 구조 표현은 텍스트로: "완료", "주의", 굵은 글씨, 표
- 예외(기능적 사용): 부모로 2기 아바타 시스템(동물 이모지 12종)처럼 이모지가 기능 그 자체인 경우 — 단 신규 도입 시엔 사용자에게 확인
- 토스 그래픽 규칙(아이콘·이모지 과다 금지)과도 일치
