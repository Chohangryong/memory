**한 달 동안 300만 원 벌기** (~/Desktop/한달300만원벌기/, 2026-08-08 시작, 실입금 마감 09-04 금).

**Why:** 사용자가 30일 내 순수익 300만원 계획을 요청 → 멀티에이전트 적대검증 루프(47 에이전트, 5라운드)로 수립. 1차 루프(300만 고정): 18표 전원 기각, 최고안 28% — "콜드스타트 직장인 300만/30일"은 어떤 구조로도 50% 문턱 통과 불가. 지배 변수 = **겸업 규정 게이트(외생)** × 미검증 전환율 곱셈. P(30일 내 판매창 개방) ≈ 0.41이라 목표액을 낮춰도 무조건부 현금 목표는 통과 불가. 2차 루프에서 **이원 목표 구조**만 통과(3인 만장일치 85·88·93%): 30일 = 검증자산 5종(분기판정문서·실측퍼널·포트폴리오+후기·크몽 심사·조건부 견적서) + 분기 조건부 현금(A 확정 시 실입금 50만), 300만 = D150 로드맵(~2027-01-04, 상한 D180).

**How to apply:**
- 실행 기준선 = `PLAN.md`(검증 통과안). 스트레치 = `PLAN-스트레치-300만.md`(25~30%, 조건부). 루프 이력 = `후보검토.md`.
- 선행 게이트: 8/10(월) 취업규칙 겸직 조항 원문 판정(A1 무규정/A2 신고제/B 승인제/C 금지형, 모호하면 B 보수 분류). 판정 문서화 전 플랫폼 등록·유상활동 금지.
- 이해충돌 전면 배제: 이커머스 인접(상품등록 대행·[[project-honyongnyul-program]] 혼용률 툴·셀러 타깃) 판매 금지 — 소속 부서 업무와 중첩.
- 확정 팩트: 숨고 수수료 0%·정산=거래확정 후 1시간·매크로/VBA 평균 견적가 15만, 크몽 첫 구간 실효 21.7%·신규 계정 30일 내 현금 구조적 불가(리뷰 자산용), 부업 직장인 월평균 부수입 52~62.3만.
- 사용자 승인 대기 상태로 종료(2026-08-08) — 실행 개시 전 계획 검토 필요.
